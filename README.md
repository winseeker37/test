# 국방예산 대시보드 (web)

`index.html`을 더블클릭해 브라우저로 열면 됩니다. 인터넷 연결이나 서버가 없어도 동작합니다.

## 사용법
1. 처음 열면 `2027년_국방예산.xlsx` 예시 데이터가 표시됩니다.
2. 오른쪽 위 상자를 눌러 엑셀(.xlsx/.xls) 또는 CSV 파일을 고르거나, 페이지에 끌어다 놓습니다.
3. 탭: **분야별**(규모·증가율·분야 카드 → 사업별 비교) / **신규사업**(순위·분야별 비중·상세) / **전체 목록**(검색·필터·정렬).
4. **집계 CSV 저장**: 분야 합계와 사업 목록을 CSV로 내려받습니다.

## 입력 파일 형식
상단 10행 안에 아래 열 제목이 있으면 자동 인식합니다(열 순서 무관, 시트가 여러 개면 선택 가능).

| 의미 | 인식하는 제목 예 | 필수 |
|---|---|---|
| 분야 | 분야, 영역, 부문, 중점 | 권장 |
| 사업명 | 사업, 지표, 항목, 과제 | 필수 |
| 단위 | 단위, 구분 (없으면 억원) | |
| 전년 | 2026, 26년, (A), 전년 | 권장 |
| 당해 | 2027, 27년, (B), 정부안, 당해 | 필수 |
| 증가율 | 증가율 — '신규'라고 적으면 신규사업 | |
| 내용 | 내용, 근거, 비고, 설명 | |

- 분야 칸이 비어 있으면 바로 위 행의 분야를 이어받습니다(병합 셀 대응).
- **신규사업** = 전년이 0·빈칸이거나 증가율 칸에 '신규'라고 적힌 사업.
- 증감·증가율은 전년·당해 값으로 다시 계산합니다(엑셀 수식 결과에 의존하지 않음).
- 단위가 백만원·천만원·원이면 억원으로 환산하고, 명·% 등 금액이 아닌 단위는 합계에서 제외합니다.
- CSV는 UTF-8과 엑셀 기본 저장(CP949) 모두 읽습니다. `template.csv`가 양식입니다.

## 파일 구성
- `index.html`, `style.css`, `app.js` — 대시보드
- `sample-data.js` — 처음 표시할 예시 데이터
- `lib/xlsx.full.min.js` — 엑셀 읽기 라이브러리(SheetJS, 오프라인용 동봉)
- `template.csv` — 입력 양식
